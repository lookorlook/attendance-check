# 🌍 多国考勤工时整合工具 (Multi-Country Attendance Tool)

> 把打卡记录和排班表合并，自动算工时、调休、加班费，生成彩色 HTML 日历报表。  
> 支持多国规则（比利时、法国…），新增国家只需 JSON 配置文件，**无需改代码**。

---

## 1. 为谁服务

**跨国企业的 HR / 薪酬核算人员**，特别是那些需要处理：

- 🌐 **多国劳工法规**（比利时 38h 门槛 + TOIL 调休 / 法国 35h 周 + 梯度费率）
- 🈶 **多语言考勤数据**（中/英/法文混合的员工姓名、排班标记）
- 📂 **多数据源打通**（线上打卡系统导出 + HR 线下排班表合并）

---

## 2. 解决什么场景

### 多国合规考勤计算的"最后一公里"难题

大型企业常面临两个数据孤岛无法打通的问题：

| 痛点 | 我们的方案 |
|------|-----------|
| 系统打卡与排班表格式不同、命名不一致 | 📥 **自动模糊匹配**，打通两套数据源 |
| 每换一个国家就要重写一套计算逻辑 | 🧠 **JSON 规则引擎**，比利时/法国开箱即用，新增国家只改 JSON |
| 周总工时门槛、TOIL 调休池、多梯度费率等复杂规则 | ⚖️ **内置合规计算**，自动处理 |
| 请假类型繁多（CM/VA/OFF/RECUP…） | 📋 **请假类型映射表**，可自由配置 |

**一句话**：HR 每月花 1-2 天手算的考勤报表 → **现在 1 分钟出结果**。

---

## 3. 产出什么结果

生成一份 **交互式 HTML 月度工时日历报表**，浏览器打开即看：

| 功能 | 说明 |
|------|------|
| 🎨 **颜色编码** | 白色🟦正常 / 黄色🟡调休 / 红色🔴加班费 / 蓝色🔵请假 / 紫色🟣休息 |
| 🔍 **员工搜索** | 下拉选择 + 文字搜索，月份切换自动保留 |
| 📅 **每日详情** | 实际工时 / 标准工时 / 调休(TOIL) / 加班费 |
| 📊 **周汇总 + 月汇总** | 正常工时、调休、加班费自动分开统计 |
| ⚠️ **异常自动标注** | 不满勤、缺卡、待确认项自动列出 |

## 🚀 快速开始（免安装版）

> 不需要装 Python，双击就能跑。

### 下载

`
https://github.com/[你的用户名]/belgium-attendance-skill/releases
`

### 使用步骤

**第 1 步：准备两个 Excel 文件**

| 文件 | 来源 | 格式 |
|------|------|------|
| **打卡记录**（data1） | 考勤机系统导出 | 第3行起：工号、姓名、打卡时间 |
| **排班表**（data2） | HR 线下登记 | 第2行星期、第3行日期、第4行起姓名+排班 |

**第 2 步：修改配置**

用 **记事本** 打开 config.json，修改这三项：

`json
{
  "country": "belgium",
  "file_paths": {
    "data1": "D:/你的打卡文件路径.xlsx",
    "data2": "D:/你的排班表路径.xlsx"
  }
}
`

> 路径怎么找：右键点击 Excel 文件 → 属性 → 复制"位置"路径，加 / 和文件名。  
> 斜杠用 / 不用 \。  
> 国家可选：elgium（比利时）、rance（法国）

**第 3 步：双击运行**

双击 un_attendance.exe（或 双击我运行.bat），等待几秒。

**第 4 步：查看报表**

打开 output/attendance_calendar.html，浏览器查看彩色日历。

## 🔧 修改规则（不用改代码）

### 修改已有国家的规则

用 **记事本** 打开 ules/ 里的对应 JSON 文件：

`json
{
  "employee_classes": [{
    "standard_hours": { "hours_per_day": 7.6 },        // ← 改日标准工时
    "weekly_pool": {
      "normal_up_to": 38,                               // ← 改周加班门槛
      "overtime_rate": 1.0                              // ← 改加班费率
    }
  }],
  "leave_types": {
    "CM": "病假", "VA": "年假", "OFF": "休息"           // ← 改请假类型
  }
}
`

改完保存，重新运行即可生效。

### 添加新国家

1. 复制 ules/example.json 重命名为 ules/你国家代码.json
2. 用记事本修改参数（标准工时、加班门槛、请假类型…）
3. 在 config.json 中把 country 改成你的文件代码
4. 运行

**全程只改 JSON 文本文件，不碰任何代码。**

### 让 AI 帮你加

你可以直接把规则需求描述给 AI（如 ChatGPT / Codex）：

> "请帮我生成日本考勤规则 JSON：每天标准8小时，周40小时起算加班，费率1.25倍，请假类型有年休、病欠、公休"

AI 会直接输出可用的 JSON 文件，丢进 ules/ 文件夹即可。

## 📁 文件结构

`
belgium-attendance-skill/
├── README.md                       ← 本文件
├── run_attendance.exe              ← 免安装运行（双击）
├── 双击我运行.bat                   ← 或双击这个
├── 使用说明.txt                     ← 简易说明
├── config.json                     ← 你的配置文件（改路径）
├── config_template.json            ← 配置模板
├── rules/                          ← 国家规则
│   ├── belgium.json                ← 比利时规则
│   ├── france.json                 ← 法国规则
│   └── example.json                ← 自定义模板
├── skill_belgium_attendance/       ← 源码（不需动）
└── output/                         ← 生成结果
    └── attendance_calendar.html    ← 打开看报表
`

**日常只需接触 3 个文件：**
1. config.json — 告诉程序你的文件在哪
2. ules/xxx.json — 想改规则就改它
3. output/attendance_calendar.html — 每月生成的报表
